# harnessctl example notebooks

These notebooks are lightweight command walkthroughs. They use shell cells and do not require Python packages.

- `01-quickstart-handoff.ipynb`: run Codex, hand off to Claude Code, then inspect logs.
- `02-compare-and-judge.ipynb`: compare Codex and Claude Code, add a judge, and inspect the generated report.
- `03-pipelines-and-failover.ipynb`: chain agents in a pipeline and configure fallback behavior.

Run them from a disposable git repo when you want agents to edit files.
